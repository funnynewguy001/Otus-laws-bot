# Otus — бот базы законов Majestic RP

Каждую ночь (02:00 МСК) бот заходит на форум Majestic RP служебным аккаунтом и скачивает
законодательную базу, уставы ведомств и правила проекта — только темы, изменившиеся с
прошлого раза. Готовые архивы выкладываются в релиз `laws` репозитория
`funnynewguy001/Otus-SKDA`, откуда их берёт программа Otus у игроков.

Логин, пароль бота и токен выкладки хранятся в секретах репозитория и в код не попадают.
